# Nabdalmalaeb.scrip — نظام أتمتة أخبار نبض الملاعب

نظام يجلب أخبار كرة القدم (عربية وعالمية)، يترجمها ويعيد صياغتها بالعربية عبر
الذكاء الاصطناعي، وينشرها كمسودات في ووردبريس، مع تقرير تلجرام بعد كل دورة.

## ⚠️ قبل البدء
1. أنشئ Application Password **جديدة** في ووردبريس (المستخدمون ← ملفك الشخصي).
2. أنشئ مفتاح OpenAI **جديد**.
3. لا تضع هذه القيم الحقيقية في أي محادثة أو مكان عام — فقط داخل `config.json` محليًا،
   أو داخل GitHub Secrets عند التشغيل السحابي.

## هيكل الملفات

| الملف | الوظيفة |
|---|---|
| `config.py` / `config.json` | تحميل الإعدادات (من الملف محليًا، أو من متغيرات البيئة على GitHub Actions) |
| `db.py` | قاعدة بيانات SQLite لمنع تكرار النشر |
| `rss_fetcher.py` | جلب الأخبار (عربية + عالمية) من Google News RSS، بحد فحص أقصى |
| `article_extractor.py` | حل رابط جوجل، استبعاد النطاقات الممنوعة، استخراج النص والصورة |
| `content_ai.py` | ترجمة (إن لزم) + إعادة صياغة + عنوان + تصنيف عبر OpenAI |
| `wordpress_publisher.py` | فحص المصادقة، رفع الصورة، حل التصنيفات (بدون إنشاء جديد)، نشر المسودة |
| `telegram_reporter.py` | إرسال تقرير تلجرام بعد كل دورة |
| `main.py` | الملف الرئيسي الذي يشغّل كل شيء |
| `.github/workflows/run_bot.yml` | تشغيل تلقائي مجاني كل 30 دقيقة عبر GitHub Actions |

---

## الطريقة 1: التشغيل المحلي على Pydroid 3

1. انسخ كل الملفات إلى مجلد واحد على الهاتف.
2. `pip install -r requirements.txt` من Terminal داخل Pydroid.
3. انسخ `config.example.json` وسمّه `config.json`، وضع بياناتك الحقيقية بداخله
   (بما فيها قسم `telegram` إن رغبت بتفعيل التقارير محليًا أيضًا).
4. شغّل `main.py`.

---

## الطريقة 2: التشغيل التلقائي المجاني كل 30 دقيقة عبر GitHub Actions (موصى بها)

### الخطوة 1 — إنشاء مستودع خاص
أنشئ مستودعًا جديدًا **خاصًا (Private)** على GitHub، وارفع إليه كل ملفات هذا
المشروع **باستثناء** `config.json` الحقيقي (استخدم `config.example.json` فقط،
وأعد تسميته لاحقًا إلى `config.json` داخل المستودع — قيم الأسرار بداخله ستبقى
Placeholder لأنها ستأتي من GitHub Secrets وقت التشغيل).

### الخطوة 2 — إضافة الأسرار (Secrets)
من صفحة المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**،
أضف كل سر بهذا الاسم بالضبط:

| اسم السر | القيمة |
|---|---|
| `WP_USERNAME` | اسم مستخدم ووردبريس |
| `WP_APP_PASSWORD` | Application Password |
| `OPENAI_API_KEY` | مفتاح OpenAI |
| `TELEGRAM_BOT_TOKEN` | توكن بوت تلجرام (من @BotFather) |
| `TELEGRAM_CHAT_ID` | معرّف مجموعة تلجرام |

### الخطوة 3 — التفعيل
الملف `.github/workflows/run_bot.yml` سيبدأ العمل تلقائيًا كل 30 دقيقة بمجرد
رفعه للمستودع. يمكنك اختباره فورًا يدويًا من تبويب **Actions ← نشر أخبار كرة
القدم التلقائي ← Run workflow**.

### ملاحظات مهمة
- GitHub Actions يوقف تلقائيًا الجداول الزمنية (schedule) للمستودعات الخالية من
  أي نشاط (commit) لمدة 60 يومًا — أي نشاط بسيط (حتى تحديث news.db التلقائي) يبقيه فعالًا.
- الحصة المجانية 2000 دقيقة/شهر للمستودعات الخاصة — تشغيل السكربت كل 30 دقيقة
  يستهلك جزءًا صغيرًا منها فقط (كل تشغيلة تستغرق دقيقة إلى دقيقتين عادة).

## كيفية الحصول على بيانات تلجرام

1. تحدث مع **@BotFather** في تلجرام، أرسل `/newbot` واتبع التعليمات للحصول على `bot_token`.
2. أضف البوت لمجموعتك كعضو (وامنحه صلاحية إرسال الرسائل).
3. للحصول على `chat_id` للمجموعة: أرسل أي رسالة في المجموعة، ثم افتح في المتصفح:
   `https://api.telegram.org/bot<التوكن>/getUpdates`
   وابحث عن `"chat":{"id": -100xxxxxxxxxx ...}` — هذا الرقم (بما فيه الإشارة السالبة إن وُجدت) هو `chat_id`.

## إعدادات قابلة للتعديل في config.json

| الحقل | الوظيفة | الافتراضي |
|---|---|---|
| `fetch_settings.max_articles_checked_per_cycle` | أقصى عدد أخبار يُفحص لكل دورة | 100 |
| `fetch_settings.max_articles_published_per_cycle` | أقصى عدد مقالات يُنشر لكل دورة | 20 |
| `global_sources.enabled` | تفعيل/تعطيل جلب مصادر عالمية (Marca، Sport، ESPN، إلخ) | true |
| `global_sources.locales` | قائمة اللغات/الدول الإضافية للبحث | en/US، es/ES |
| `blocked_domains` | قائمة النطاقات الممنوع الجلب منها | hihi2.com، alwasat.ly |

## ملاحظات عامة (من التجربة العملية)

- **الفلترة الرياضية**: `EXCLUDED_SPORTS_KEYWORDS` في `rss_fetcher.py` تستبعد رياضات أخرى بعدة لغات. أضف أي كلمة جديدة تلاحظ مرورها بالخطأ.
- **التصنيفات**: يجب أن تُكتب في `config.json` بنفس الإملاء **الحرفي** الموجود فعليًا في ووردبريس (تحقق من صفحة التصنيفات عندك)، وإلا لن يتم تعيينها للمقال (الكود لا يُنشئ تصنيفات جديدة أبدًا بتصميم متعمد).
- **إذا توقف النشر فجأة**: أول شيء تحقق منه هو رسالة فحص المصادقة في أول سطرين من السجل — تشرح السبب مباشرة قبل أي محاولة فحص.
